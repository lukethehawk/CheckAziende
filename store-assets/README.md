# Store assets

Reusable publication assets for browser-extension stores.

## Included

- `icon-128.png`: square store/extension icon.
- `logo-horizontal.png`: complete CheckAziende logo.
- `promo-440x280.png`: small promotional tile.
- `promo-1400x560.png`: wide promotional artwork.
- `listing-it.md`: Italian store copy.
- `listing-en.md`: English store copy.

## Screenshots

Real product screenshots still need to be captured from the final signed/release build.

Recommended source size: 1280×800 or larger, then crop per store requirements.

Suggested subjects:

1. company automatically identified with financial summary;
2. company data + balance-history accordion;
3. unidentified/manual VAT lookup state.

Do not publish screenshots containing personal browsing data that is not part of the product demonstration.
